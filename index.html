Round 3
JavaScript Challenge
Students implement form validation in script.js using VS Code. Download the ZIP to begin.
JavaScript Tasks
01Select the registration form and all input fields using getElementById or querySelector.
02Attach a submit event listener to the form element.
03Call event.preventDefault() inside the listener to stop the page reloading.
04Read and trim values from: fullName, email, phone, courseSelect, password, confirmPassword.
05Validate that name and course are not empty strings.
06Validate email format using regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/.
07Validate phone is exactly 10 digits: /^\d{10}$/.
08Validate password is at least 6 characters long.
09Check that confirmPassword exactly matches password.
10Display inline error messages in the .error-msg spans beside each invalid field.
11Clear all previous error messages before re-running validation on each submit attempt.
12If all validation passes: show success in #formSuccess, then call form.reset().
